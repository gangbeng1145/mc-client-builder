========================================
  MC 客户端构建器 v1.2
========================================

一、这是什么
  不依赖启动器的 Minecraft 客户端下载 / 配置 / 打包工具。
  选好版本和加载器，它会自动下载原版、依赖库、资源文件，
  调用官方安装器装好 Forge / OptiFine / Fabric / Quilt，
  最后打包成一个 zip。把 zip 解压出的文件夹作为 HMCL 的游戏目录，
  就能直接启动，不需要再补下载。

二、怎么用
  1. 双击 MC客户端构建器.exe
  2. 左侧选 Minecraft 版本（可搜索、可筛正式版/快照/远古）
  3. 选加载器与版本（原版可以跳过）
  4. 选 Java：没有合适版本就点「安装 Java」，
     工具会从 Mojang 官方下载运行时（8 / 16 / 17 / 21 / 25），
     下载到「构建目录\java」，装完自动选中
     （Forge 1.13+ 需要 Java 17+，1.12.2 建议 Java 8）
  5. 选「构建目录」和「输出目录」
  6. 点「开始构建」，等进度条走完
  7. 到输出目录取 <实例名>.zip

三、版本清单加载失败怎么办
  程序内置了一份离线版本清单（920 个版本）。
  如果联网拉取清单失败，会自动切换成内置清单，版本列表仍能显示。
  下载游戏文件仍然需要网络。

  界面右下角有「网络诊断」按钮，点一下会检查：
    DNS 解析 / 443 端口 / HTTPS 请求 / 系统代理 / 系统时间
  把诊断结果发给我，就能定位是虚拟机没联网、时间不对，还是网络被拦。

  常见原因：
    1. 虚拟机网络模式是「仅主机」→ 改成 NAT 或桥接
    2. 虚拟机挂起恢复后系统时间停在过去 → 同步 Windows 时间
    3. 代理软件没开或做了 HTTPS 拦截 → 关掉代理重试

四、在 HMCL 里启动
  方式一（推荐）：
    把 zip 解压出的文件夹整个作为 HMCL 的游戏目录
    （HMCL → 设置 → 游戏目录 → 选择该文件夹）
  方式二：
    把 zip 里 versions、libraries、assets 三个文件夹
    一起合并进现有 .minecraft

  注意：libraries 和 assets 必须一起带，只复制 versions 会缺文件。

五、常见问题
  * 首次启动慢（5-10 秒）：单文件 exe 要先解压，正常现象。
  * 杀毒软件误报：PyInstaller 单文件常见误报，加信任即可。
  * 下载慢：换「下载源」或调整「下载线程」。
  * Forge 1.13+ 不能叠加 OptiFine，工具会明确报错。
  * 只支持 Windows 10 / 11 64 位。

六、系统要求
  Windows 10 / 11 64 位
  需要本机已安装 Java（工具会自动扫描；没有 Java 无法构建）
  磁盘空间：建议预留 5 GB 以上（构建目录 + 输出 zip）
